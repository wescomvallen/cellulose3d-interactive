About Cellulose3D Interactive

Cellulose3D Interactive creates games worth playing, and software that makes 3D game development easier in Scratch.

Featured Software

Wireframe Modelling Tool

Wireframe Modelling Tool is a 3D modelling software by Vallen Alexander that allows you to create primitive 3D models with ease. Featuring plugin support, multiple models & objects, and a user interface powered by FlexiGUI 3.0, this software allows you to create the best 3D model you can imagine.

FlexiGUI

FlexiGUI is a user interface engine by Vallen Alexander that lets you build competent, multiple-menu graphical user interfaces easily using code.
