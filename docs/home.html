Adding Community Documentation

To add a documentation page for your community-made software for Cellulose3D's software, you can request to add it by sending an email to my contact address here.

Mailing format, what needs to be included

To add a documentation, you must give a reason why your software should have documentation listed here, and a document containing everything about the software, in good understandable formatting, written in English. Mark the email as important and send it, I will respond and build the documentations page in a few days.
